# Licensing

Two licences, split along a real line rather than a convenient one.

| Path | Licence | SPDX |
|---|---|---|
| `principles/**` | Creative Commons Attribution-ShareAlike 4.0 International | `CC-BY-SA-4.0` |
| everything else | Apache License 2.0 | `Apache-2.0` |

Full texts: [`LICENSE`](LICENSE) and [`LICENSE-CC-BY-SA-4.0.txt`](LICENSE-CC-BY-SA-4.0.txt).

## Why the split

`principles/` is not a program. It is a frame of reference stating what this
instrument investigates and how. ShareAlike is the point: a case file's
authority rests on citing a frame that can be inspected, and a closed fork
producing case files against rules nobody can read would hollow that out.

The code is Apache 2.0 — permissive, as a tool should be, but with an explicit
patent grant, clearer warranty and liability language, and an explicit
non-grant of trademark rights.

## On the name

No licence governs a name. A fork may change the rules and still call its
output a Heimdall case file. What makes the claim checkable is that every case
file names the frame it was produced under. Trust the identifier, not the name.

## What is not licensed here

Case files are covered by neither licence and are not distributed with this
repository. They cite code that is not ours to relicense and carry findings
about how identifiable people worked. Whoever receives one owns its
retention.
